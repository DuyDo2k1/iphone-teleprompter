# Prompt

A minimal, private iPhone teleprompter. It has one editable script, adjustable speed and text size, horizontal mirroring, a three-second countdown, and offline Home Screen use. There are no accounts, ads, analytics, or dependencies.

## Put it on GitHub Pages

1. Create a new public GitHub repository and upload everything in this folder, keeping the `icons` folder intact.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**. Select `main`, choose `/ (root)`, and save.
4. Open the web address GitHub shows after deployment finishes.

## Install on iPhone

1. Open the GitHub Pages address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Launch **Prompt** from its new Home Screen icon. Turn the iPhone sideways before reading.

The app asks for landscape orientation where browsers support it, but iPhone Safari does not reliably allow websites to lock orientation. If rotation is locked in Control Center, unlock it and rotate the phone manually.

Your script and settings are stored only in that browser on that device. After the first successful visit, the installed app can work offline.
